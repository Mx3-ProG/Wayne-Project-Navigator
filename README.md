# Wayne Project Navigator

The Wayne-Web client portal: onboarding, project brief, billing, and delivery tracking for Wayne-Web clients, plus a super-admin console for the team.

## Development

You need [Bun](https://bun.sh) installed.

```sh
git clone <this-repository-url>
cd <repository-name>
bun install
bun run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
- Supabase
